# Enterprise Network Design

## Overview

This project demonstrates the design and implementation of a production-inspired multi-site enterprise network using Cisco Packet Tracer. The infrastructure connects a Headquarters (HQ) with two branch offices through redundant WAN links and GRE tunnels.

The network follows a three-tier enterprise architecture consisting of Core, Distribution, and Access layers. Redundancy is implemented at both the LAN and WAN levels using HSRP, EtherChannel, dual ISP connectivity, and GRE tunnels.

---

## Enterprise Architecture

- Headquarters (HQ)
- Branch Office 1
- Branch Office 2
- Three-Tier Campus Architecture
- Dual ISP Connectivity
- Dual Cisco ASA Firewalls
- Dedicated DMZ
- Server Farm
- Wireless Infrastructure
- Enterprise Voice Network
- CCTV & NVR Network
