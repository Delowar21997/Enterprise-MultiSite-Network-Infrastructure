# Troubleshooting Guide

| Issue | Possible Cause | Resolution |
|-------|----------------|-----------|
| OSPF Neighbor Down | Area mismatch or interface issue | Verify OSPF configuration and interface status |
| BGP Neighbor Idle | ASN or connectivity issue | Verify peer IP, ASN, and WAN connectivity |
| GRE Tunnel Down | Routing or source interface issue | Verify tunnel source, destination, and routing |
| HSRP Failover Issue | Priority or tracking configuration | Verify HSRP settings and interface tracking |
| Inter-VLAN Routing Failure | VLAN or SVI issue | Verify VLANs, SVIs, and trunk links |
| DHCP Failure | DHCP Relay or Pool issue | Verify DHCP Server and IP Helper configuration |
| DNS Resolution Failure | Missing DNS record | Verify DNS A records |
| Mail Connection Timeout | Routing, Gateway, or Mail Server issue | Verify server connectivity and SMTP/POP3 configuration |
| Wireless Client Failure | SSID or Security mismatch | Verify WLAN and client configuration |
