# Configuration Guide

The project includes the following major configurations:

## Routing

- OSPF
- eBGP
- GRE Tunnel

## High Availability

- HSRP
- Interface Tracking

## Switching

- VLAN
- Inter-VLAN Routing
- EtherChannel
- IEEE 802.1Q Trunk
- PVST+

## Enterprise Services

- DHCP
- DNS
- Web
- Mail
- File Server
- WLC
- IP-PBX

## Security

- Basic Cisco ASA Integration
- ACL
- NAT
