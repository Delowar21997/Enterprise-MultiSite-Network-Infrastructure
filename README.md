Enterprise Multi-Site Network Infrastructure

A practical Cisco Packet Tracer project that simulates a real-world enterprise network connecting a Headquarters (HQ) with two branch offices. The network is designed with redundant WAN connectivity, dynamic routing, VLAN segmentation, and centralized enterprise services to provide a reliable, scalable, and secure infrastructure.

---

## Project Overview

This project was built to demonstrate how an enterprise network can be designed and implemented using Cisco technologies. It includes redundant ISP connectivity, secure GRE tunnels between sites, dynamic routing with OSPF and eBGP, VLAN-based network segmentation, EtherChannel for link redundancy, and essential enterprise services such as DNS, DHCP, Mail, Web, VoIP, and CCTV.

The goal was to create a network that closely reflects the design principles used in production enterprise environments while improving hands-on experience with routing, switching, and network services.

## Features

- Dual ISP connectivity for WAN redundancy
- Headquarters connected with two branch offices
- GRE tunnels for secure site-to-site communication
- eBGP for ISP connectivity
- OSPF as the internal routing protocol
- VLAN segmentation for different departments
- Inter-VLAN routing
- EtherChannel (LACP) for link redundancy
- Dual firewall architecture
- Dedicated DMZ network
- Wireless LAN Controller (WLC)
- Corporate and Guest Wi-Fi
- IP-PBX for VoIP communication
- CCTV and NVR infrastructure
- DNS, DHCP, Web, Mail, and File servers
